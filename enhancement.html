Enhancements

1. Hover Effect on Cart Items

This enhancement adds a hover effect on each cart item in the shopping cart page. When the user hovers over a product, the card slightly lifts and the shadow becomes stronger. This improves user interaction and provides visual feedback.

Code used:

.cart-item:hover {
  transform: translateY(-5px);
  box-shadow: 0 8px 20px rgba(0,0,0,0.1);
}

Link: View Cart Page

2. Image Zoom on Hover

This enhancement applies a zoom-in effect to product images when the user hovers over the cart item. It makes the product more visually engaging and helps highlight product details.

Code used:

.cart-item:hover .product-img {
  transform: scale(1.1);
}

Link: View Cart Page

3. Button Interaction Effects

This enhancement improves button interactivity by adding hover animations. Buttons slightly move upward and change color when hovered, giving a more modern UI feel.

Code used:

.checkout-btn:hover {
  transform: translateY(-2px);
  background: #3e2501;
}

Link: View Cart Page

4. Improved Form Layout Design

This enhancement improves the layout of the registration form. The fields are styled with rounded corners, spacing, and focus effects. Additionally, the City and State fields are arranged side by side using flexbox, making the form more compact and user-friendly.

Code used:

.row {
  display: flex;
  gap: 15px;
}

.row .input-group {
flex: 1;
}
